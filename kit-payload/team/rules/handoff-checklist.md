# Handoff Checklist

Before asserting current state or proposing next steps (when resuming work or switching agents):

1. Read the project's root CLAUDE.md.
2. Read the .claude/rules/ files relevant to the area you are working on.
3. Read .claude/memory/decisions.md for the last major decisions and open questions.
4. Only then summarize current state and propose next actions.

Never rely on recollection alone when claiming project state. On any discrepancy between memory and files, files win.
