# Reference library

Put trusted source material for this project here: product docs, standards, style guides, market reports, past proposals, transcripts, and books or long-form guides you own the rights to use. Markdown and text work best; PDFs work too.

Why this folder exists: agents that answer from real sources beat agents that answer from vibes. The researcher checks this folder before searching anywhere else, and findings that cite a document here outrank general knowledge. More grounding, less generic filler.

House rules:

- Only add material you have the right to use (your own files, your purchases for your own use, public documents, freely licensed work).
- Name files so a human can guess the contents: `brand-voice-guide.md` beats `doc-final-v2.pdf`.
- Big libraries are fine, but prune what goes stale. A wrong reference is worse than none.
- Nothing in here is read automatically on every turn; agents pull from it when a task calls for sources. Point at a specific file in your request when you want it used for sure.
